# 나는 미디어아티스트, OOO! (장애학생 맞춤형 시·청각 경험 및 미디어 아트 기반 감각 통합 플랫폼)

> 장애 학생의 일상 시·청각 경험을 비디오 기록과 미디어 아트로 재해석하여, 공감각적 인지 학습과 상황 일반화를 돕는 맞춤형 행동 수정 플랫폼입니다.

## 1. 프로젝트 소개
- 주 사용자: 교사와 학생
- 문제 영역: 생활교육·상담
- 결과물 형태: 모바일앱
- 완성 상태: 아이디어

## 2. 해결하려는 문제
장애 학생은 자신이 경험한 시·청각적 상황을 개별적으로 재인지하거나 일상 맥락으로 일반화하는 데 어려움을 겪습니다. 기억은 본래 그 상황의 ‘이미지’와 ‘감각(시·청각 느낌)’으로 형성되나, 기존의 정형화된 매체는 이를 온전히 복원하지 못합니다. 이에 따라 단발성 경험에 그치지 않고, 일상에서 느낀 시·청각 경험 및 감각적 느낌을 비디오 포맷 및 미디어 아트로 변환·치환하여 지속적으로 학습하고 일반화할 수 있는 플랫폼입니다. 

## 3. 해결 방법
학생의 개별 시·청각 경험을 쉽게 촬영 및 수집하고, 이를 인지 학습과 행동 수정에 최적화된 짧은 비디오 콘텐츠 및 미디어 아트 파티클 효과로 치환·저장하하고자 합니다. 
[기본] 비디오 학습: 학생별 상황 맞춤형 비디오 라이브러리를 구성하여 실제 맥락 기반의 반복 학습을 지원합니다.
[심화] 미디어 아트 치환: 보이지 않는 청각 및 감각 자극을 실시간 미디어 아트(Visual Image)로 변환해 공감각적 창작 표현합니다.

## 4. 핵심 기능
- 실생활 비디오 학습
- 미디어 아트 변환
- 디지털 갤러리

## 5. 사용 흐름
1. 실생활 비디오 학습 탭에서 상황에 맞는 비디오 모듈을 재생하고, 행동 수정 평가를 기록합니다.
2. 공간-청각 미디어 아트 탭으로 이동하여 마이크를 연결(또는 시뮬레이션 시작)합니다.
3. 학생의 소리에 맞춰 생성되는 미디어 아트를 체험한 뒤, '작품 저장'을 눌러 [작품집] 디지털 갤러리에 기록합니다.

## 6. 검토 및 개선
- 자기 점검 — 고친 것: 개인정보보완지침 / 방법: 하단에 명시함. / 분류: 오늘 고침 / 고치지 않기로 한 것: 세부내역
- AI 점검 — 고친 것: 개인보안 / 방법: 카메라 기능 활성화, 사용자 개인정보 변경, / 분류: 오늘 고침 / 고치지 않기로 한 것: 색감, 기능, 활성화 내용
- 동료 점검 — 고친 것: 플랫폼 구현 타입 / 방법: 하이브리드 기능을 중심으로 구현 / 분류: 오늘 고침 / 고치지 않기로 한 것: 하이브리드 구현 중심으로 바로 적용이 어려움
- 동료에게 남긴 피드백: 2건

- 개인정보 처리: 개인정보를 처리함
- 배운 점: 개인정보 기능과 권한을 바탕으로 안전한 실험과 검증
- 다음 계획: 학생 성장 최우선
