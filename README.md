# 🎨 나는 미디어아티스트, OOO!

**장애학생 맞춤형 시·청각 경험 및 미디어 아트 기반 감각 통합 플랫폼**

실생활 비디오 기반 인지 반복 학습부터 공간 청각 반응형 미디어 아트 체험까지, 학생 개별 감각 특성에 맞춘 공감각 통합 환경을 제공하는 웹 애플리케이션입니다.

## 🌟 주요 기능

### 1. 🎬 [기본] 실생활 비디오 학습
- **비디오 모듈 제공**: 보조공학기기 반응, 횡단보도 시그널 인지, 급식실 적응 등 맞춤형 인지 학습.
- **다양한 재생 옵션**: 재생 속도 조절(0.5x, 0.75x, 1.0x), 구간 반복, 자막 기능 지원.
- **행동 수정 평가**: 상황 재인지 및 일반화 체크리스트를 통한 학생의 수행 여부 기록.
- **피드백 보드**: 교사와 보호자 간 실시간 피드백 기록 및 공유.

### 2. ✨ [심화] 공간-청각 미디어 아트 (Interactive Canvas)
- **소리 감지 반응**: 실제 마이크 연동 및 데모 시뮬레이터를 통해 소리의 음량(dB)과 주파수에 실시간 반응.
- **맞춤형 파티클 스타일**: 파스텔 버블, 오로라 웨이브, 스파클 스타버스트, 지오메트릭 링 등 다양한 시각적 피드백 제공.
- **광과민성 보호**: 급격한 섬광이나 강한 빛의 점멸을 차단하는 '자극 완화 이징(Easing)' 안전 장치 탑재.
- **공간 배경 선택**: 특수 학습실, 일반 교실, 급식실 등 상황에 맞는 배경화면 지원.

### 3. 🖼️ [작품집] 디지털 갤러리
- **포트폴리오 생성**: 학생이 직접 상호작용하여 생성한 미디어 아트 결과물 아카이빙.
- **Google Drive 연동**: 완성된 아트 작품을 구글 드라이브 내 `/MediaArtist_Portfolio` 지정 폴더에 안전하게 클라우드 백업 및 동기화.

## 🛠 사용 기술 (Tech Stack)
- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS
- **Fonts & Icons**: Pretendard 폰트, FontAwesome
- **API/Integration**: Google Identity Services, Google Drive API

## 🚀 웹 구동 및 사용 흐름 (3단계)

웹 애플리케이션을 구동하고 사용하는 핵심 3단계 흐름입니다.

### 1단계: 웹 애플리케이션 실행
저장소를 다운로드한 후, 폴더 내의 `index.html` 파일을 더블클릭하여 Chrome 또는 Edge 브라우저에서 실행합니다. 
*(Vercel 등으로 배포된 경우 해당 웹 링크로 바로 접속합니다.)*

### 2단계: 학생 선택 및 학습 모듈 진행
우측 상단의 학생 프로필을 클릭하여 학습을 진행할 대상 학생을 선택합니다. 이후 **[기본] 실생활 비디오 학습** 탭에서 상황에 맞는 비디오 모듈을 재생하고, 행동 수정 평가를 기록합니다.

### 3단계: 미디어 아트 체험 및 갤러리 저장
**[심화] 공간-청각 미디어 아트** 탭으로 이동하여 마이크를 연결(또는 시뮬레이션 시작)합니다. 학생의 소리에 맞춰 생성되는 미디어 아트를 체험한 뒤, **'작품 저장'**을 눌러 **[작품집] 디지털 갤러리**에 기록합니다.

## 🔒 Google Drive 연동 안내 (선택 사항)
학생들의 미디어 아트 작품을 실제 구글 드라이브에 저장하려면 클라이언트 ID 설정이 필요합니다.
1. 갤러리 탭 우측의 **[Drive 설정]** 버튼을 클릭합니다.
2. 발급받은 `Google OAuth Client ID`를 입력하고 저장합니다.
3. **[Google Drive 연결]**을 클릭하여 계정을 인증하면 동기화 기능이 활성화됩니다.
*(클라이언트 ID를 입력하지 않아도 데모 시뮬레이션 백업 모드를 통해 동작을 테스트해 볼 수 있습니다.)*
